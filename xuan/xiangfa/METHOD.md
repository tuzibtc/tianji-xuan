# 相法（面相 + 手相）

1. **命相合参**：相用来佐证和补充紫微盘，不单独定吉凶。
2. **看神不只看形**：形是五官和纹路，神是气色和动作；照片上的气色基本不可靠。
3. **步骤**：收正脸、侧脸、左手掌心照片，确认是谁、多大年纪、性别 → 对照 `rules.json` 的面部宫位逐宫记录特征（看不清就写看不清）→ 套用 M01–M16、P01–P14，每条写「看到什么 → 对应哪条」→ 有紫微盘就交叉核对，一致才下较强结论。
4. **说法**：不评美丑；凶的说法一律改成「要多经营」「要留意、建议体检」，不预测生死。结论末尾写「仅供参考」。
5. 从照片识别特征受光线、角度、美颜影响很大，要说明把握程度。
